# React 프레임워크 보충

사용하는 프레임워크의 항목만 적용한다. 특정 라우터·라이브러리·버전으로 전환하지 않는다.

## 라우팅·데이터 계층 공통

- 라우팅·조회·폼·전역 상태는 기존 프레임워크와 프로젝트 계층을 재사용한다. 같은 기능의 별도 요청 클라이언트·라우터·상태 저장소를 만들지 않는다.
- 로딩·데이터 없음·실패를 구분한다. 요청 실패를 빈 목록으로 표시하지 않고 공통 오류 경로를 사용한다.
- 화면 로컬 상태는 컴포넌트 또는 관련 Hook에 둔다. 실제 여러 화면이 공유할 상태만 전역으로 올린다.

## Next.js

- 먼저 실제 버전과 App Router/Pages Router를 확인하고 해당 규칙을 적용한다. 파일명·라우트·조회 방식을 두 체계 사이에서 섞지 않는다.
- App Router의 클라이언트 경계는 브라우저 API·상태·이벤트 처리가 필요한 범위에 둔다. 모든 파일에 'use client'를 일괄 추가하지 않는다.
- 서버 전용 비밀정보·DB 코드는 클라이언트 코드와 props에 넣지 않는다. 경계를 넘는 데이터는 해당 프레임워크의 전달 계약을 따른다.
- 조회·캐시·재검증·로딩·오류 처리는 기존 프로젝트 방식과 해당 버전 API를 사용한다. 다른 버전의 기본 캐시 동작을 가정하지 않는다.
- 서버 동작에서도 입력·권한을 검증한다. 화면에서 숨겼다는 이유로 접근 제어를 생략하지 않는다.

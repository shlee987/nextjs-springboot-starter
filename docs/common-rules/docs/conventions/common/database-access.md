# DB 실행 권한

- AI의 DB 접속은 데이터·스키마를 변경하지 않는 조회만 기본 허용한다. SQL 첫 키워드가 아니라 실제 부수 효과로 판단하며, 변경 가능성이 불명확하면 실행 전에 확인한다.
- 데이터 변경·DDL·변경 가능한 프로시저·마이그레이션 실행은 대상 DB·환경, 실행 SQL 또는 명령, 영향 범위와 복구 방법을 제시하고 사용자의 명시적 승인 후 수행한다. 복구가 불가능하거나 확인되지 않으면 그 사실을 명시한다.
- SQL·Mapper·기능 작성 요청은 DB 변경 실행 승인으로 간주하지 않는다. 승인된 대상·작업·범위 안에서만 실행하고 같은 범위의 승인은 다시 요청하지 않는다.
- 테스트·스크립트·애플리케이션 실행을 통한 간접 DB 변경에도 같은 기준을 적용한다. 롤백 예정·개발 DB라는 이유로 승인을 생략하지 않는다.
- 가능한 읽기 전용 계정·연결을 사용한다. 이 문서는 AI 행동 규칙이며 실제 DB 권한을 변경하거나 기술적으로 차단하는 설정은 아니다.

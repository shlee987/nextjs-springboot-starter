# 새 파일 템플릿

- 해당 언어의 README에서 필요한 템플릿 하나만 선택한다. 프로젝트 템플릿이 있으면 우선한다.
- `.template` 파일은 생성 예시이며 직접 빌드·import할 소스가 아니다. {{이름}} 자리표시자를 실제 값으로 교체하고 최종 확장자로 저장한다.
- 이름·설명·패키지·타입은 실제 역할에 맞춘다. 인터페이스·record·Hook을 만들기 위해 템플릿을 억지로 사용하지 않는다.
- 한국어 역할 설명을 기본으로 작성한다. 회사명·작성자·날짜·저작권을 추측해 넣지 않는다.
- 실제 처리에 맞게 필요한 구간 주석만 추가한다. 빈 TODO·사용하지 않는 import·자리표시자를 완성된 파일에 남기지 않는다.
- JS 프로젝트에서는 TS 타입을 제거하고 필요한 JSDoc 타입을 작성한다. 언어·의존성을 템플릿에 맞춰 바꾸지 않는다.

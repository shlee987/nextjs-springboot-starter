# 공통 보안 요구사항

> 2026-10-29 적용 갱신: 이 문서의 조항 ID는 유지한다. 인증/세션/동시3개/JWT조건부/로그 수준의 이전 기본안은 [최종 설계](../backend-foundation.md)로 대체하고 [새 검증표](../backend-handoff.md)의 BF/LG/AU/AT/FEI/SEC ID와 연결해 검증한다. 과거 검토·시험 기록을 새 JWT 기능의 통과 증거로 사용하지 않는다.

범위: Next·Spring API·DB·진입 서버·공개 저장소·빌드 및 배포. 상태: 설계, 구현 전.
이 문서의 ID는 프로젝트 관리용이며 ASVS 조항 번호가 아니다.

## 요구사항과 책임

| ID | 필수 구현·설정 | 책임 | 통과 조건 |
| --- | --- | --- | --- |
| SEC01 | 버전·지원기간·구성요소·공개 범위·데이터 분류 목록 | 설계 | D01·D05·D06 기록, 지원 종료 구성의 무근거 채택 없음 |
| SEC02 | 인증과 매 요청 권한 확인, 기본 거부 | API | 미인증·타 사용자·낮은 권한·다른 테넌트 우회 실패 |
| SEC03 | 입력 경계 검증과 문맥별 출력 처리 | FE/API | 타입·크기·범위·인젝션·XSS 회귀 통과 |
| SEC04 | 비밀값 외부 주입, 공개 결과물 검사, 누락 시 실패 | 전체 | 소스·번들·로그·이미지·CI 산출물에 실제 비밀값 없음 |
| SEC05 | HTTPS·신뢰 프록시·DB 암호화·계정 분리 | 운영/API | 인증서 검증과 네트워크 격리, 권한 거부 검사 통과 |
| SEC06 | CSP·쿠키·캐시·보안 헤더 계약 | FE/API/운영 | 실제 외부 응답과 브라우저 기능·차단 동작 통과 |
| SEC07 | 인증 수명주기·CSRF·CORS·속도 제한 | API/운영 | 위조 요청·오래된 자격·금지 출처·한도 초과 거부 |
| SEC08 | 오류·보안 감사·경보·개인정보 최소화 | API/운영 | 오류는 안전한 계약, 진단과 감사는 제한된 로그에 기록 |
| SEC09 | 공개 저장소와 CI 공급망 보호 | CI/관리자 | 신뢰하지 않는 PR에 배포 권한·비밀값·지속 runner 없음 |
| SEC10 | 정적·의존성·비밀값·배포 동적 검증 | 검수 | verification.md 차단 기준 통과와 증거 보관 |
| SEC11 | 백업 복구·키 회전·사고 대응·업데이트 | 운영 | 실제 복구·폐기/회전 시험과 담당·기한 기록 |
| SEC12 | 추가 기능을 기본 비활성으로 유지 | 설계/개발 | 업로드·배치·웹훅 등 도입 전에 조건부 계약 완료 |

## 환경별 강제 범위

| 환경 | 허용 예외 | 필수 유지 |
| --- | --- | --- |
| local | 루프백 HTTP, 개발 HMR·eval·스타일 예외만 명시적으로 분리 | 권한·입력 검증·CSRF, 실제 시크릿 비공개, 루프백 바인딩 |
| dev | local 완화 자동 상속 금지, 외부 주입·별도 자격 | HTTPS·안전한 쿠키·입력/권한/CSRF 유지 |
| test/preview(배포 프로파일 아님) | 합성 데이터와 격리 DB·계정. 신뢰하지 않는 PR은 운영 자원 접근 불가 | HTTPS 배포면 운영 헤더·쿠키·CSP, 검색·접근 노출 제한 |
| stg | 운영과 동등한 보안 설정·렌더링·프록시, 별도 자격·합성 데이터 | 실제 브라우저와 외부 응답·권한 검증 |
| prod | 승인·문서화된 최소 예외만 | 안전한 시작 실패, TLS·인증·권한·감사·검사 관문 전체 |

local이라는 이유로 전체 보안 필터를 해제하지 않는다. 테스트 더블과 가상 사용자·DB는 격리된 검사 구성에서만 허용하며 운영 빌드에 포함하지 않는다.

## 위협 경계

보호 대상은 인증정보·사용자 데이터·업무 변경·소스 공급망·실행 권한이다. 주요 경로는 브라우저 입력, API ID 조작, 외부 URL/파일, 프록시 전달 헤더, 공개 PR, 의존성 및 관리 포트다. CDN·프록시·Next·Spring·DB 각각에서 다른 경계를 통과한다. 내부망이라는 이유로 API 권한을 생략하지 않는다.

출처: [OWASP ASVS](https://asvs.owasp.org/), [WSTG](https://owasp.org/projects/web-security-testing-guide). 구체 통제와 수치는 이 프로젝트의 설계 선택이며 ASVS 전체 준수 선언이 아니다.

## 공통 기준 보완 0.2

[controls](controls.md)의 GOV01~GOV15를 기존 요구사항의 구체 계약으로 함께 적용한다. SEC02→GOV02/GOV04/GOV05, SEC03→GOV01/GOV03, SEC04/SEC05→GOV06/GOV10, SEC06/SEC07→GOV11/GOV12, SEC08/SEC11→GOV07/GOV08/GOV09, SEC09→GOV14, SEC12→GOV13/GOV15다.

[ASVS 대조표](asvs-mapping.md)는 전체 345개 ID를 분류·연결한다. 공통 기준 검토 완료와 실제 구현의 조항별 검증 완료를 구분한다.
